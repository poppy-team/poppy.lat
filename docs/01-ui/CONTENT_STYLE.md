# Estilo de conteúdo

## Voz

Clara, curiosa e específica. Evitar superlativos, linguagem promocional vaga e alegações técnicas sem fonte. Preferir parágrafos curtos e títulos que descrevam o conteúdo.

## Idiomas

- Português brasileiro é a versão raiz.
- Inglês fica em `/en/` com paridade de navegação; slugs podem variar por tradução e cada artigo liga para sua tradução quando existe.
- Nomes próprios de linguagens, ferramentas e sintaxe não são traduzidos.

## Alegações

- Descrever cada linguagem pela documentação/repositório de origem.
- Diferenciar linguagem compilada, VM e backend JavaScript sem sugerir que qualquer uma seja executada no site.
- Tratar diagramas editoriais como ilustrações, nunca como captura de interface.
- Para docs espelhadas, registrar revisão, blob, licença e URL da fonte.
