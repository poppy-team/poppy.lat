::: info Cópias estáticas
As páginas abaixo são cópias estáticas selecionadas dos repositórios canônicos,
fixadas em revisões identificadas. As fontes originais permanecem canônicas e as
cópias locais não são atualizadas automaticamente.
:::

- [Ori](/docs/ori/) — Uma linguagem de leitura cuidadosa, tipos explícitos e compilação nativa.
- [Aipo](/docs/aipo/) — Uma linguagem dinâmica e fortemente tipada, com contratos opcionais.
- [Oride](/docs/oride/) — Um editor de código e IDE leve para o terminal, escrito em Rust.
- [Prumo](/docs/prumo/) — Um protocolo Git-native para colaboração entre pessoas e agentes de IA.
