# ADP-003 — Execution Budgets

- **Status**: Approved & Implemented
- **Deciders**: Poppy Team
- **Phase**: Wave 1

---

## Context

When running untrusted scripts in host environments (game engines, plugin sandboxes, or user-authored automations), preventing infinite loops from locking the host process is non-negotiable.

---

## Decisions Taken

1. The VM supports an optional maximum instruction execution limit (*gas / instruction budget*).
2. Each dispatch cycle decrements steps from the budget counter when active.
3. Reaching zero triggers a deterministic termination fault: `AIPO_RT_BUDGET_EXCEEDED`.
