# ADP-009 — Synchronous Versioned C ABI

- **Status**: Approved & In Implementation
- **Deciders**: Poppy Team
- **Phase**: Wave 6 (P05)

---

## Context

To enable embedding Aipo as a scripting engine in hosts written in C, C++, Zig, or other systems languages without requiring complex Rust bindings, a **stable synchronous C ABI** is indispensable.

---

## Decisions Taken

1. **Opaque Types**:
   - `aipo_vm_t`, `aipo_bytecode_t`, `aipo_value_t`.
2. **Synchronous Execution**:
   - Zero-allocation VM instantiation and instruction dispatch.
3. **Clean Memory Contracts**:
   - Explicit cleanup and deallocation routines (`aipo_vm_free`).
   - Numeric diagnostic fault codes returned according to Aipo's canonical diagnostic catalog.
