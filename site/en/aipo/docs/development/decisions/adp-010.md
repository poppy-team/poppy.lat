# ADP-010 — Provas Finas de Interoperabilidade (Rust, C, JS)

- **Status**: Aprovado & Em Implementação
- **Decisores**: Poppy Team
- **Fase**: Wave 6 (P05)

---

## Contexto

Garantir que a promessa de interoperabilidade da v0.1.0 não seja apenas teórica, mas validada por testes reais em cada um dos ecossistemas suportados.

---

## Decisões Tomadas

1. **Proof 1 — Rust Embedding**:
   - Criação de fixture em `tests/` demonstrando a inicialização de uma instância `aipo_vm::Vm`, passagem de argumentos Rust nativos e recuperação de resultados.
2. **Proof 2 — C Host Embedding**:
   - Um pequeno programa em C que carrega a biblioteca estática compilada, compila um script Aipo simples e extrai o valor de retorno.
3. **Proof 3 — JavaScript/Node.js Host**:
   - Um script em JavaScript consumindo o código emitido pelo `aipo-js`, comprovando interoperabilidade no ecossistema npm.
