## Como este arquivo funciona

As páginas desta seção são cópias estáticas de um conjunto allow-listed de documentos públicos. Cada fonte tem uma revisão Git fixada e uma licença registrada no [manifesto de fontes](/docs/sources.json).

Os repositórios de [Ori](https://github.com/poppy-team/ori-lang) e [Aipo](https://github.com/poppy-team/aipo-lang) continuam sendo as fontes canônicas. A seleção não representa a documentação completa de nenhum dos projetos.

:::caution[Escopo desta prova técnica]
Conteúdo interno de engenharia não é publicado. Cada exemplo é texto estático: esta página não executa código Ori ou Aipo no navegador.
:::
