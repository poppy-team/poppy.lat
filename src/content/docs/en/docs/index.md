## How this archive works

Pages in this section are static copies from an explicit allow-list of public documents. Each source has a pinned Git revision and a license recorded in the [source manifest](/docs/sources.json).

The [Ori](https://github.com/poppy-team/ori-lang) and [Aipo](https://github.com/poppy-team/aipo-lang) repositories remain canonical. This selection is not the complete documentation for either project.

:::caution[Proof-of-concept scope]
Internal engineering content is not published. Every example is static text: this page does not run Ori or Aipo code in the browser.
:::
